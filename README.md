# Structural Programming Language

A collection of **C programming exercises, practice problems, and lab work** completed while learning the fundamentals of structured programming.

This repository documents my progress from basic C syntax to functions, loops, recursion, strings, and structures.

## 📚 Contents

The repository is organized by topic and source.

### Core C Topics

- Variables and data types
- Input and output
- Conditional statements
- `for`, `while`, and `do-while` loops
- Nested loops
- Functions
- Recursion
- Strings
- Structures
- Basic problem solving
- Mathematical problems such as factorials and binomial coefficients

## ▶️ How to Run

You need a C compiler such as **GCC**.

Clone the repository:

```bash
git clone https://github.com/ahbabcodes/Structural-Programming-Language.git
cd Structural-Programming-Language
```

Compile a program:

```bash
gcc "path/to/program.c" -o program
```

Run it:

### Windows

```powershell
./program.exe
```

### Linux / macOS

```bash
./program
```

> **Note:** Some filenames contain spaces, so wrap the file path in quotes when necessary.
