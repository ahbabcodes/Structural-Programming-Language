# W3Schools Practice

C examples and exercises that follow the **W3Schools C tutorial**. Each folder matches a tutorial chapter and contains the programs I typed out and experimented with while learning.

## 📂 Chapters

| Folder | Topic |
| --- | --- |
| `Intro` | Hello World and the structure of a C program |
| `Output` | `printf`, new lines, tabs, quotes, and backslashes |
| `Variables` | Declaring, changing, and combining variables; format specifiers |
| `Data Types` | Integers, floats, characters, and memory size of types |
| `Type Conversion` | Implicit and explicit conversion (e.g. computing a percentage) |
| `Operators` | Arithmetic, comparison, logical operators, and precedence |
| `Boolean` | Boolean values in C |
| `If...else` | `if`, `else`, `else if`, nested `if`, and short-hand `if...else` |
| `Switch` | `switch` statements |
| `Loop` | `while` loops |
| `Strings` | Character arrays, string length, modifying strings, looping through strings |
| `Practice Problems` | Small exercises such as Say Hello, Even or Odd, and Celsius to Fahrenheit |

## ▶️ How to Run

From the repository root:

```bash
gcc "w3schools/Intro/Hello World.c" -o hello
./hello
```

On Windows, run `./hello.exe` instead. Keep the quotes around paths with spaces.

## 🎯 Note

These programs are based on W3Schools' teaching examples and are kept here as a learning record, not as original projects.
